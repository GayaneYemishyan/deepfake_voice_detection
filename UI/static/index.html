How it works
01
Feature Extraction
227 acoustic features — MFCCs, delta-MFCCs, spectral centroid, chroma, tonnetz, F0, GFCC, LFCC, HNR and more — extracted using librosa.
02
Temporal Analysis
Audio is split into overlapping 2-second windows. Each window is scored independently to reveal where in the recording synthetic artifacts appear.
03
MLP Inference
A 4-layer MLP (512→256→128→64) with BatchNorm and GELU activations produces a fake-probability score, fully consistent with the per-second timeline chart.
